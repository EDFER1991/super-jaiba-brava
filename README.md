# SUPER JAIBA BRAVA — El camino a ser campeón

Juego de plataformas en 8 bits hecho con HTML5 Canvas, sin librerías. Funciona en computadora y en celular, donde aparecen botones táctiles.

**Jugar:** https://edfer1991.github.io/super-jaiba-brava/

## Controles
| Acción | Teclado | Celular |
|---|---|---|
| Mover | ← → o A / D | ◀ ▶ |
| Saltar | Espacio / Z / ↑ | A |
| Correr | Shift / X | B |
| Pausa | P / Esc | START |
| Sonido | M | — |

## Niveles
1. **1-1 Playa de La Ceiba**
2. **1-2 Selva Catracha**
3. **1-3 Nacaome, Valle**
4. **1-4 ¡El Pirata!**: hay que darle 3 golpes en la cabeza al jefe.

## Archivos
- `index.html` + `js/game.js` + `assets/`: versión web.
- `SuperJaibaBrava.html`: todo en un solo archivo, se abre con doble clic.
- `tools/prepare_assets.py`: recorta y prepara los sprites desde `assets/src/`.
- `tools/build_single.py`: genera `SuperJaibaBrava.html`.

Para practicar un nivel, agrega `?nivel=2`, `?nivel=3` o `?nivel=4` al final del link.
